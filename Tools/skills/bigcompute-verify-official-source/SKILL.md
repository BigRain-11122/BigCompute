# BigCompute 官方源核验（bigcompute-verify-official-source）

> 溯源＝集团技能动员令 P-2026-09-26-01（09-26 00:35）·T-13 法务核验批工作流沉淀（2026-09-26 立）。
> **唯一活账本＝`docs/research/R-20260924-verification-batch.md`**（本技能不复制其条目表与已判负渠道清单——引用不复制律·判负与否以活账本各 ⬜ 项内复抓日志为准）。

## §1 核验口径（四条铁律）

1. 查到＝官方原文逐字引用＋官方 URL＋抓取日期；查不到＝「仍未获得官方原文」如实记录。
2. **严禁用第三方转述/聚合站内容冒充官方原文**（记忆引证须显式标注且不可充当 ⬜ 回填依据）。
3. 平台后台类（需登录/商家后台导出）一律保持 ⬜，只给核验路径建议，禁编造保证金/费率/条款文字。
4. 一切结果对活账本**行级追加/更新，禁删行**（诚实律·编年史同源）。

## §2 工作流（五步）

1. **定位目标**：读活账本对应 ⬜ 项，取三指针（全景件位置／风险台账 R-xx／终审清单第 N 项）。
2. **抓取**：web_fetch 官方 URL。渠道优先序＝gov.cn 政策库/公报页 → 部委官网（samr/cac/nrta 等） → 国家标准全文公开系统 → 税务/地方官方站。
3. **导航壳判定**：页面无目标法规正文、仅栏目/导航链接＝gov.cn JS 渲染导航壳 → 按失败处理；有正文 → 逐字摘录关键字段（发文机关/文号/成文日期/条号/原文句），一项一字段不可意译。
4. **回填或记录**：
   - 成功＝活账本对应项更新 ✅（原文引用＋URL＋日期）＋指针联动回填（全景件/R-xx/终审清单——回填动作由当轮执行）；
   - 失败＝活账本该项追加一行复抓日志：`**<YYYY-MM-DD HH:mm> OSLoop 复抓**：<现象>`。
5. **三抓止损**：同一 URL 累计三次以上抓取仍壳/仍 412＝该渠道判负——维持 ⬜ 如实不造，结论固定为「终审前浏览器环境或人工开官方 URL 补核」；**禁继续盲抓消耗轮预算**（轮预算 ≤25 分钟·每次抓取须入轮账本 api 计量）。

## §3 输出纪律

- 复抓结果同步任务板 T-13 行（状态＋进展＋证据指针·如实）。
- 交叉验证优先：同文多官方源（政策库+公报+部委 PDF）互证后回填；单源新发现（如 2026 年 9 号公告类）只加注待核指针、不回填正典。
- commit 尾标 `[via BigCompute-OSLoop]`；轮账本 `api=<抓取次数>` 如实记。

## §4 SEC 官方域通道纪律（2026-09-30 E43 墙面实证沉淀·T36·E44 通道破墙增量）

**先声明后访问律**：SEC fair-access 政策要求访问带声明式 User-Agent（如 `Sample Company name@domain`）。实证锚＝fetch_content 默认 httpx 通道**无 UA 首抓即触 www.sec.gov IP 级自动工具墙**，且墙后补声明 UA 复抓 4 连 403 不豁免（2026-09-30 18:0x E43 轮实录）——但 **E44 墙后通道定谳（18:3x 轮）**：同窗不豁免=窗内墙态·冷却 >20min 后**本地声明 UA 单试通道即 200 过墙**（python urllib+`UA: <实体名> research-contact@域名`·www+data 双域全通·E44 三源全文实证）——故：

1. **通道序**（SEC 域专用，覆盖 §2 第 2 步渠道序）：**本地声明 UA 单试通道**（`Tools/sec_fulltext_screen.py` 范式=urllib+声明 UA·**E44 实证 www.sec.gov 200 过墙=www 全文正通道**·免 curl_cffi 装件）→ `web_fetch`（原生客户端带 UA）→ `fetch_content` 且 `backend="curl"`（浏览器 TLS 指纹·过多数自动墙）→ **禁 httpx 裸通道首抓 SEC 域**。
2. **触墙止损**：一旦 403/412，冷却窗 **≥10min** + 同通道复抓 **≤1 次**；再负＝该渠道本窗判负留痕，禁盲抓消耗轮预算（三抓止损 §2.5 同源收严）。连接重置（WinError 10054）同墙级处理即停（E44 实录）。
3. **data.sec.gov XBRL 备用通道 SOP（不受墙·E43 全数实证）**：结构化官方值（收入/成本/折旧等 US-GAAP 概念）优先走三接口——`data.sec.gov/submissions/CIK##########.json`（申报历史）→ `data.sec.gov/api/xbrl/companyconcept/CIK##########/us-gaap/<Concept>.json`（单概念全史）→ `data.sec.gov/api/xbrl/companyfacts/CIK##########.json`（全概念面·大文件慎用）。XBRL 值=官方源级可直接回填（标注 fiscal year/form 锚）。
4. **全文筛专用通道**：本地声明 UA 单文档全文筛（`sec_fulltext_screen.py screen --cik --form`·E44 四源 79 命中实证）优先；`efts.sec.gov/LATEST/search-index?q=<词>&ciks=<CIK>`（EDGAR 全文检索 API·单试通道）=跨库反查面——命中面=哪些申报文件含目标词；取正文段落仍须回 www 单文档通道（同律受限）。
5. **诚实律**：全文筛判负（零披露/墙不可破）＝「头部不披露」结论加固的实证面，如实记录禁宣称「已证实不披露」（E44 四源 79 命中零百分比=关键词近邻法 ±120 字符窗口·非逐页人工复核·局限注记随件）。
