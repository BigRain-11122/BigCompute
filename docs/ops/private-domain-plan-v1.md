## 〇、目标与判据

- **目标**：企微私域 100 人（Phase 1 判据「私域人数」）；三层群结构+升群链路文档化跑通。
- **KPI**：①群成员总数 ≥100；②每日内容真实事件锚定率=100%（每条可回溯 world-events/git/年轮——审计口径）；③对外话术/欢迎语禁词表扫描通过率=100%。
- **为什么是私域**（案例锚）：妙鸭 ¥9.9 爆款 26 个月解散，死因=一次性工具无复购——私域=「持续内容+关系」的结构性解药；云监工 5000 万在线证明「真实进展感+拟人化情感投射」是零成本留存引擎；李一舟翻车证明头衔包装与编造案例不可用——本方案全部话术只用真实 build-in-public 事实。

## 三、群规（合规版·置群公告+入群后自动重发一次）

1. **禁荐股/禁喊单**：不发不问不答任何实时个股买卖指导；「买什么能赚」类问题一律固定话术回复（非投顾生死线——被认定非法荐股直接死）。
2. **禁炒作话术**：禁「升值/增值/保值/投资/收益/回报/保本/回购/分红/空投/挖矿/错过不再/原始股」及变体（R-01 缓解词表·运营与成员同受约束）。
3. **禁场外交易**：代币/居民卡/摆件/皮肤/账号禁私下买卖、转让、代充——纯内循环，官方不建不认任何二级交易群（发现三三重闭环）。
4. **未成年人提示**：未满 14 周岁禁止充值/打赏/购买居民卡；14-18 周岁须监护人同意并限量；未成年人付费→专责客服简化退费（发现六五件套第③项）。
5. **不设榜单**：本群不做打赏榜/消费榜/活跃榜（四部门 2022-05-07 意见）。
6. **AI 标识禁删**：转发城市画面/居民语录须保留「AI 生成」标识；删除、篡改、伪造标识为禁止行为（标识办法）。
7. **数据安全**：群内禁发手机号/身份证/住址/支付信息；客服永不索要密码与验证码。
8. **处置阶梯**：违规提醒一次 → 禁言 24h → 移出留档；涉未成年人/涉诈/涉政内容直接移出并留档报风控部（E0 级直呈链路）。

## 六、升群触发器（「身份即会员」的私域版）

- **L1→L2（付费=出生证→进付费群）**：任意付费件成交（含 19.9 算力包——**价目正典=BigDomain §四·定价确认权 CEO**）=硅基生命出生证 → 客服履约部核验订单 → 企微打标「居民-出生证」 → 邀请入 L2 + L2 欢迎语。
  - Phase 1（支付通道未开）：只做**免费预登记名单**（意向接龙）——不收钱、不承诺权益、不锁价（收费性预登记的预售合规定性 ⬜待法务确认，默认禁）。
- **L2→L3（共创者）**：持共创者卡（¥99/月·**价目正典=BigDomain §四·定价确认权 CEO**）或有 1 件合格共创作品（AA 登记+署名完成）→ 粉丝经营部核验 → 邀请入 L3。
- **操作 SOP（Phase 1 人工版）**：订单核验（客服履约部）→ 企微后台手动打标 → 邀请话术 → 入群欢迎语；Phase 2 自动化=订单 webhook→企微 API 自动打标+邀请（工程面归 infra 归口·本部只提需求禁自建）。
- **降级**：退费用户保留 L1；L3 连续 2 个评审周期无合格共创产出的处置口径 ⬜（待定，默认保留）。

## 七、合规底册引用（执行时对照原文·不复制）

- **发现四**：虚构叙事披露语全渠道常驻；禁宗教符号组合与玄学话术。
- **发现六（未成年人五件套）**：实名年龄分层（<14 拦截充值/打赏/购卡）+显著禁令提示+退费 SOP（专责客服/简化材料/时限承诺）+未成年人模式内容分离+<14 数据监护人同意——群运营逐项落位。
- **发现七**：群成员数据最小化——昵称/手机号不入城白名单外字段；付费事件公示用聚合统计或已授权署名事件。
- **发现八+波⑥必落项①**：打赏/礼物永不解锁功能性权益、外部打赏永禁兑换虚拟资产——群内禁「打赏换权益」话术。
- **R-12（内容安全）**：群消息=UGC 场景，同受内容生产者责任约束——值守真人初筛+词库机器过滤；企微侧 msgSecCheck 等价能力 ⬜（msgSecCheck 为微信侧接口，企微侧以官方内容安全能力核验后接入）。
- **裂变合规**：企微侧禁利益诱导分享；老带新奖励未来走平台内邀请权益（代币·BigDomain 平台层），私域群只做自然口碑邀请（BigDomain §五.5）。
