## 二、通用门禁（一切可挂 SKU 上车前逐项 ✓·任一 ✗ 不挂）

1. **挂车权限与类目**：平台购物车/挂车权限+类目在册（B站挂车权限/类目待实测 ⬜·抖音小店类目随开店=M1 清单）——号=BigStream 资产面（D-20260924-08）·挂载操作=本司·双面签核（§四.1）。
2. **商品页底座**：上架流程六步过闸（merchandise-listing-v0 §四）+详情页结构七项+禁用词自检 0 命中（§三禁用词行）+法务终审清单 10 项。
3. **定价确认**：挂载价=CEO 定价确认批落值·未批 SKU 禁挂（定价确认权=CEO·促销价另过毛利线闸=SOP §五）。
4. **AIGC 标识叠加**：标识从源头带律（主图/物料生成时即带·不可裁切位）+虚拟场景款起始画面显著标识（第四条(五)）+协议载明标识样式（第八条）+无标识导出日志 ≥6 个月（第九条）——引流物料不打标=限流（SOP §三.5·BigStream 消费面承接·本司成交面执行）。
5. **原价口径（促销态）**：一切划线价/折扣/被比较价过 SOP §三.1-2（促销前 7 日真实成交最低价·新品无成交史=直标价禁划线）——56 号令原文级未过=条款文字级禁引用（核验批项十五·价格口径表述以平台模板字段+复验后回填为准）。
6. **两线分离**：订单话术与打赏/礼物话术严格分立（打赏=自愿赠与零权益暗示·城市生长只看订单·livestream-plan §4.4 口径）——购物车讲解禁捆绑打赏权益暗示。
7. **快照留档**：挂载物料快照（含 AIGC 标识版）+档期/库存真实底账入价格档案五件（SOP §四）·留档 ≥ 活动期+6 个月。

## 三、SKU 专项门禁组（叠加组·先决件齐才可挂）

1. **订阅族**（会员三档/29.9 入门档若裁 A/数据年报订阅档）：自动续费合规六条页面化+实测留档（接受前提醒+续费日前显著提醒+默认勾选禁令+≤2 步取消+停服预案=未消费余额按比例退还+数据导出删除窗口）——docs/legal/service-continuity-terms.md v0.1 全文先决。
2. **抽卡/盲盒族**（居民卡抽卡·促销联动抽卡款）：公示模板定值+概率真实律可审计+未成年人双门禁（<8 周岁禁售+≥8 周岁监护人同意）+月消费上限强制件+成瘾提示+二次确认+无空盒——七件齐才可挂（blind-box 件 §三/§四/§七）。
3. **稀缺族**（加急/限量款/纪念藏品）：真实队列/库存数据接口对接（虚构「仅剩 N 件/最后 X 小时」=违 SOP §三.3）·倒计时与后台一致·限售编号轨公示一致。
4. **围观族**（策略围观）：非投顾提示常驻话术位（禁荐股禁收益承诺）。
5. **生成族**（摆件/角色/房间/分身建档）：履约直播留证链（下单→生成过程直播→城内可见）+SLA 口径话术一致（≤30min 目标/最长 24h）+电子凭证链路（兑换码+核销日志）。
6. **直签族**（B 端/广告/包场）：直播间只口播+私域预约（docs/ops/b2b-playbook-v1.md）·禁挂车·禁口播价外报价——购物车语义=平台内电子订单面（履约映射件 §三管线外四类语义）。
