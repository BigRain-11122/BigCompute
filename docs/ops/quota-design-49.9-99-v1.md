## 二、价值感线与区隔参考线

- 价值感下限（配额设计律·同律各档）：Q_min = 1.5 × E_单包 = 1.5 × 243 = 364.5 tokens/月（0.0003645 Mtok/月·M12 发布值 365/0.000365=舍入口径）——E_单包=243 tokens 实测锚（2026-09-28 22:43 dry-run 首单·SKU 终稿复测）。
- **约束面定谳（M12 同判）**：两档全 v1 带最保守行（v1=0.80/g=70%→49.9 档 18.7／99 档 37.1 Mtok）对 Q_min 余 51,337×／101,852× → **价值感线（下界）退化为非约束·约束面=毛利线闸（上界）唯一**。
- **区隔参考线（C-20260927-01 席6 防蚕食护栏+席4 权益区隔附款·建议级）**：订阅族 N 阶梯等比 2×——29.9 档 N=15~30（M12 §三）→ **49.9 档 N=30~60** → **99 档 N=60~120** 次/月（单包等效）；即 Q_49.9 ≈ 0.0073~0.0146 Mtok/月、Q_99 ≈ 0.0146~0.0292 Mtok/月。权益面（独占功能/身份等）归商品运营部·配额面=本件。
