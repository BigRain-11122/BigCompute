## 二、四个真发现

1. **真漏检面=0 行**：没有任何一行口播是裸文本。334 字引号外字符全部落在 PARTIAL 行，
   形态二类——段标题标签（「1. 城市进度条：」这类 label）与纪律/元文本（素材铁律、打赏话术纪律、
   「基础段=原文维持」说明）。即**当前稿件里「只扫引号」不构成漏检**，M152 的 0 命中判据未被推翻。
2. **4 处引号外命中全是禁令自述**：plan L179「禁运势/算命/预测/八字」、L200「禁自我打赏与打赏返现」。
   与 M152 判定的「结构性假阳性四形态」同族；此处如实列出待人工确认，不自动豁免。
3. **队列行引用的 §4.6 不存在**：livestream-plan §四 只有 4.1–4.4。fail-closed 闸据此报
   `VERDICT=QUOTE-COVERAGE-PARSE-SUSPECT`（exit 3），并对已解析 5 节给出独立判定
   `resolved-only=QUOTE-COVERAGE-GAP-HIT`——缺节作废整份读数会掩盖 334 字这个真数字。
4. **口径缺陷实测（本轮自捕）**：首版用正则 `「(.*?)」` 提引号跨度，遇到嵌套引号
   （§4.1 披露语里嵌了「本产品」）提前闭合，把整段引用误判成引号外——§4.1 被虚报成 123/316（38.9%）。
   改深度配对扫描后为 316/316（100%），**误差 193 字**。任何用非贪婪正则量引号覆盖的结论都要先过嵌套样本。

## 三、边界

- 只量「文本在不在引号里」，不判语义是否合规；4 处命中只列不判。
- 只读本司两件文档，未扫任何兄弟司/集团件。
