## 二、授权标签 schema（每件美术资产一行·T-16 判据「授权标签」承接）

| 字段 | 说明 |
|---|---|
| asset_id | 池内唯一编号（P-<池码>-<序号>） |
| asset_name | 资产名 |
| source | 来源四态：自绘/委托/开源/购买 |
| license | 许可证类型+许可范围（商用/改作/再分发三面） |
| commercial_use | ✓/✗——小店交付=商用面·**非 ✓ 禁入白名单** |
| whitelist | L2 直用白名单判定（✓ 入池直用/✗ 禁入） |
| provenance_note | 溯源注记（AI 生成资产=标识从源头带律义务·挂载检查表 §二.4 同律） |

**授权纪律**：①商用许可不全=禁入白名单（先授权后入池）；②开源资产=五门评估（契合/反重复/许可/健康/成本安全·OSS 借力令同律）；③AI 生成资产=AIGC 标识叠加义务入标签注记；④委托/购买资产=书面授权凭证指针入行。
