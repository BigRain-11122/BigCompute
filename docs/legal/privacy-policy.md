# 隐私政策（草案）

> 草案 v0.1·2026-09-24·法务部（波⑦依据）·终审前须：⬜项核验回填+法务部会签+CEO 过目

适用主体：BigCompute 及其运营的 AI 城市服务（与《用户服务协议》经营者信息一致⬜主体信息回填）；生效日期⬜回填。

## 一、我们收集的信息（最小化原则）

我们仅收集与服务直接相关、实现处理目的所必需的最小范围信息：

| 场景 | 收集字段 | 目的 |
|---|---|---|
| 账号识别 | 平台侧账号 ID ⬜（字段以实际接入回填） | 识别用户、履约 |
| 下单购买 | 订单号、商品、金额、下单时间、接收方式（虚拟交付不涉收货地址） | 交易履约、售后 |
| 兑换/核销 | 兑换码、核销日志、访问账号标识 | 交付凭证 |
| 直播互动 | 弹幕、连麦内容、互动记录 | 互动响应、内容安全 |
| 打赏 | 打赏流水、平台侧账号 | 结算与合规 |
| 日志 | 访问时间、设备信息 ⬜（以实际日志结构回填） | 安全审计、风控 |

我们不以「捆绑授权」「一揽子同意」方式收集；非必要信息的拒绝不影响基础服务使用⬜（拒绝后果按场景细化回填）。

> 依据指针：《个人信息保护法》（2021-11-01 施行）第四条（个人信息定义）、第六条（最小化：处理个人信息应当具有明确、合理的目的，并应当与处理目的直接相关，采取对个人权益影响最小的方式；限于实现处理目的的最小范围）【记忆引证·高置信】；《电子商务法》第十七条【记忆引证】。

## 二、委托处理与跨主体共享告知（集团内「入城」）

**1. 定性**：我们将经脱敏、去标识化处理的部分用户数据接入集团内部可视化系统（「入城」）。该接入在法律上定性为**委托处理**：集团受托方仅按我们约定的目的、期限、方式处理，不得转委托、不得超目的使用，并接受我们的持续监督；我们与受托方签署《个人信息处理协议》予以落实（模板：docs/legal/data-processing-agreement.md）。

**2. 入城字段白名单**：脱敏居民 ID、行为类型标签、时间戳、订单状态、聚合统计值。

**3. 禁入字段（红线）**：手机号、住址、支付流水号、身份证号、原始弹幕全文一律不入城（弹幕入城前经个人信息正则清洗与敏感词过滤）；不满十四周岁未成年人数据不入可视化白名单。

**4. 可视化优先聚合**：城内可视化优先展示聚合统计（人数、活跃趋势、行为类型分布）；聚合到不可识别个体的统计值不构成个人信息。

**5. 去标识化的诚实告知**：通常的「脱敏 ID」实为去标识化，借助映射表仍可复原，仍属个人信息、全程受《个人信息保护法》保护；仅达到「不可识别且不能复原」的匿名化信息才不属于个人信息——我们按「仍受约束」标准设计全链路。

**6. 独立处理者情形预告**：若未来某项入城用途由集团内独立法人自主决定处理目的与方式（而非受托处理），将构成向其他个人信息处理者提供个人信息；届时我们将另行告知接收方名称、联系方式、处理目的、处理方式、个人信息种类，并依法取得您的**单独同意**后方可实施；未经该程序不实施。

**7. 境内部署默认**：入城系统境内部署为默认架构；任何境外部署或境外云使用，在完成数据出境合规程序前不实施。

> 依据指针：《个人信息保护法》第二十一条（委托处理约定目的、期限、处理方式、个人信息种类、保护措施并监督）、第二十三条（向其他个人信息处理者提供：告知接收方名称、联系方式、处理目的、处理方式、个人信息种类，并取得单独同意）、第四条（匿名化处理后的信息不属于个人信息）、第七十三条（去标识化≠匿名化定义）【记忆引证·高置信】；《数据安全法》第二十一条（数据分类分级）【记忆引证】；数据出境合规路径（第三十八条起）另立项⬜。

## 三、未成年人条款（<14 监护人同意）

1. 不满十四周岁未成年人的个人信息属**敏感个人信息**：我们不以任何形式主动收集不满十四周岁未成年人个人信息；不满十四周岁用户无法完成充值、打赏、购买（年龄分层拦截）。
2. 确需处理不满十四周岁未成年人个人信息（含十四周岁以上未成年人个人信息）的，我们依法取得其**父母或其他监护人的同意**，并制定专门的未成年人个人信息处理规则；不满十四周岁未成年人数据不入可视化白名单。
3. 监护人可通过客服通道就未成年人个人信息行使查询、更正、删除、撤回同意等权利。

> 依据指针：《个人信息保护法》第二十八条（不满十四周岁未成年人个人信息＝敏感个人信息）、第三十一条（处理不满十四周岁未成年人个人信息应当取得其父母或者其他监护人的同意，并制定专门的未成年人个人信息处理规则）【记忆引证·高置信】；《未成年人网络保护条例》（国务院令第766号，2024-01-01 施行）【记忆引证·具体条号⬜】；四部门《关于规范网络直播打赏 加强未成年人保护的意见》（2022-05-07）（未成年人打赏退费专门受理机制·时段细节⬜）【记忆引证·高置信】。

## 四、个人信息保护影响评估（PIA）告知

1. 在入城等对个人权益有重大影响的处理活动开展前，我们进行**事前个人信息保护影响评估**，评估并记录：处理目的、方式的合法、正当、必要性；对个人权益的影响及安全风险；保护措施是否合法、有效、与风险程度相适应。
2. **评估报告和处理情况记录至少保存三年**，供监管查验。
3. 评估主要结论以简明方式在政策页与相关功能界面公示⬜（公示链接与入口回填）。

> 依据指针：《个人信息保护法》第五十五条（事前个人信息保护影响评估情形）、第五十六条（评估报告和处理情况记录至少保存三年）【记忆引证·高置信】。

## 五、您的权利与撤回路径

| 权利 | 行使路径 |
|---|---|
| 查询、复制、更正、补充 | 客服通道⬜入口回填；依法及时响应⬜时限回填 |
| 删除 | 同上；含入城数据删除（受托方同步删除） |
| 撤回同意（含数据入城处理授权） | 客服通道或账号设置入口⬜回填；撤回不影响撤回前已依法进行的处理活动的效力 |
| 注销账号 | 平台账号注销入口+客服 |
| 投诉与救济 | 客服升级→个人信息保护负责人⬜回填 |

## 六、存储、保护与期限

1. **境内存储**⬜（存储位置、保存期限清单回填）；交付凭证（电子订单+兑换码+核销日志）依法留存备争议举证。
2. 技术措施：访问控制、传输与存储加密、去标识化、入城字段白名单技术闸、弹幕 PII 正则清洗、敏感词过滤、访问与操作日志审计。
3. 制度措施：数据分类分级、PIA、跨主体《个人信息处理协议》、网络安全等级保护定级备案⬜（定级与备案编号回填）、安全事件应急预案；发生或可能发生个人信息泄露、篡改、丢失的，我们立即采取补救措施，并依法告知您与履行个人信息保护职责的部门⬜（通知时限与主管部门口径回填）。

> 依据指针：《个人信息保护法》第二十一条（委托处理到期返还或删除义务在本政策与跨主体协议双向落实）、第六条【记忆引证·高置信】；《数据安全法》第二十一条【记忆引证】；《网络安全法》第二十一条（等保定级备案——注意 2026-01-01 施行修正文本）【记忆引证】；《电子商务法》第五十一条（在线传输交付时间与交付凭证）【记忆引证】。
