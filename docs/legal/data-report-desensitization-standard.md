- 适用 SKU：N7 城市数据年报订阅（¥298-388/年·B 端直签+订阅·设计值）+城市经济实况报告（B 端定制）+后续 C 端数据订阅档——**凡「以城市/居民/集团运营实况数据为内容的对外数据产品」全适用**。
