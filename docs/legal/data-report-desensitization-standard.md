- 适用 SKU：N7 城市数据年报订阅（¥298-388/年·B 端直签+订阅·设计值）+城市经济实况报告（B 端定制）+后续 C 端数据订阅档——**凡「以城市/居民/集团运营实况数据为内容的对外数据产品」全适用**。

## 三、脱敏标准十件（核心条款·设计值）

1. **分类分级出口闸**（锚 3✅）：四级——L4 个体级原始数据（census 单卡/单居民行为流/用户原始行为/订单与支付明细）=**永不出口**（内部面白名单外零交付）；L3 小群体聚合（分组规模 <{50}）=抑制不出；L2 群体聚合统计（≥{50}）=正文可出口；L1 城市级总量与派生叙事=自由出口。阈值 {50}=设计值（k-匿名思想·锚 5🟡）·定值随法务终审+数据部实测定档。
2. **直接标识符禁出清单**（全颗粒度·含附录/附件/样例截图）：姓名/居民 ID/精确坐标/肖像/声纹/联系方式/订单号/支付凭据/**荣誉市民席身份与家人身份细节**（orders 脱敏律=永不出公开面）。
3. **间接标识符组合抑制**（再识别防线）：正文分组维度 ≤{3} 维；位置泛化到城区/街区级·时间泛化到周/月；连续值分桶；个体引述一律为叙事市民层演绎并标注虚构性质（CODEX 诚实律边界同源·只读引用）。
4. **去标识化口径定性**（锚 1✅·全景件发现七最稳口径）：交付数据集一律按「**去标识化仍属个人信息**」设计——**首版不启用匿名化出域宣称**；如未来宣称匿名化，须过 GB/T 42460-2023 效果评估（🟡）+PIA 留档+法务终审三闸方可。
5. **用户行为入城面**（master-plan 环A·只读引用）：入报告管线前先过脱敏 ID 化（映射表=内部受控资产·禁随报告交付·禁出内部面）；对外提供场景触发 **PIA**（锚 2✅·报告与记录留存 ≥3 年）。
6. **涉司供给数据授权行**（D-20260924-09 同律）：消费他司供给数据（BigLife census/behavior 导出面/BigMoney 台账面/FluxVerse 编年史面）→各出行数据授权条款行+内部协议留档（N2 三前置同构：商业物理件通+涉司数据授权行+出口记账——三前置未齐前涉用户数据面零真发）。
7. **非投顾与敏感面**：涉市场/经济背景=中性描述+「不构成投资建议」提示常驻（非折叠·R-01 E0 闸咬合）；B 端定制报告若指明投资决策用途=**拒绝该用途**条款；行情/汇率原始面禁入（§一敏感面律）。
8. **AIGC 标识叠加**（锚 6/7✅）：报告封面与每页页脚显著标识 AI 生成属性；B 端无标识交付只走标识办法第九条协议通道（导出日志留存 ≥6 个月·R-02 同律）。
9. **B 端合同使用限制十项**（商务部·条款行）：使用权许可非所有权/禁转售/禁再分发/禁再识别（禁以识别特定自然人为目的的任何处理）/禁反向工程/禁用于对自然人画像评价/接收方数据安全保管义务/泄露通知 ≤{N} 小时/违约终止+数据返还销毁义务/非投顾用途限制。
10. **审计与可验**（风控部）：脱敏管线=数据部 Tools 化（规则外置可审计·R3 再生面）；每期报告附「**脱敏声明**」（分级口径+阈值+抑制记录摘要）；**首次交付前穿透测试 ≥1 轮+年度 ≥1 轮**（判据=样本回查零个体级信息泄漏）；交付日志与脱敏声明归档 ≥6 个月。
