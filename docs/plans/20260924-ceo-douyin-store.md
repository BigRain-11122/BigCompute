# 硅基域 - 抖音小店联动开发方案（AI可读，精简版）
## 目标
打通抖音小店订单与Unity硅基域，售卖虚拟场景使用权；直播演示AI生成内容，用户共创，双向赋能。
## 业务规则
1. 商品全部通过抖音小店成交，**直播间礼物不兑换虚拟资产**。
2. 商品定位：AI虚拟场景定制服务，用户仅获得项目内使用权，不可转让、交易、炒作，无升值属性。
3. 商品分层
- 9.9元：虚拟装饰摆件
- 中档：自定义角色形象
- 高阶：独立虚拟小房间
4. 下单触发：小店订单回调 → 调用GLM大模型 → Unity自动生成资产 → 自动发放至用户硅基域账号背包。
5. 共创机制：用户提交创意建议，优质创意落地生成新资产；贡献者赠送虚拟装饰奖励。
## 直播逻辑
直播实时展示订单自动生成的全过程，作为项目演示内容；直播间打赏仅为自愿支持算力，不承诺权益。
## 约束
1. 履约、退款全部走抖音平台，无私下交易。
2. 所有AI产出素材标记AI生成。
3. 不发代币、不做资产变现。
## 闭环链路
用户小店下单→资金覆盖算力/token→AI生成资产→直播间展示案例引流→用户提交创意→扩充商品库→吸引新用户。
