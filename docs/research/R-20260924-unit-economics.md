**F1.2 消费级 GPU（4070S 级）本地推理成本——两口径**

硬件锚：RTX 4070 SUPER 发行价 $599（2024-01-08，Wikipedia GeForce RTX 40 series，2026-09-24 抓取）；TGP=220W 为官方公开规格（NVIDIA 官网 JS 拦截未逐字抓取，⬜核对；旁证：同系 RTX 4070 Ti TGP 285W 已逐字抓取）。RTX 3090：MSRP $1,499（2020-09-24 发行）/24GB GDDR6X/936GB·s⁻¹（Wikipedia GeForce RTX 30 series，2026-09-24 抓取）；TDP 350W（同页表格行抓取截断，公开规格⬜核对）。

- **口径 A·边际电费**：整机功耗 = 220W（卡）+130W（平台件）≈ 350W（假设值⬜）；推理时段平均负载 70%（假设值⬜）→ 平均 0.245kW；上海居民电价第一档 ¥0.617/kWh（公开阶梯费率·未逐字抓取⬜；超年阶梯后边际价升至第三档约 ¥0.917/kWh⬜）→ **¥0.15/机时**；单件生成 2 分钟（假设值⬜）→ **电费 ≈ ¥0.005/件**。
- **口径 B·折旧摊销**：4070S 级整机购价 ¥9,000-12,000（假设值⬜，中值 ¥10,500）；折旧期 4 年/48 月（消费级电子惯例，假设值⬜）→ 月折旧 ≈ **¥219/月**；月有效产能按 24h 理论 21,600 件×20% 有效利用率 ≈ 4,320 件（假设值⬜）→ **折旧摊销 ≈ ¥0.05/件**，加电费 **综合 ≈ ¥0.06/件**。
- **结论**：本机口径单件生成成本量级 = 角分级（¥0.05-0.10/件）；口径 A（现金）≈ 0.005 元，口径 B（全成本）≈ 0.06 元。**对 ¥9.9 定价而言，算力直接成本占比 <1%，可忽略；真正的成本大头在平台费与退款（见 F2）。**

**F1.3 直播推流算力/带宽成本**

- 算力：NVENC 硬编 1080p 增量功耗约 20-40W（假设值⬜）；画面源=FluxVerse 城市画面（CEO 原话「零新增生产成本，纯流量层」）。**1 路 24h 慢直播专机口径 ≈ 252 kWh/月×¥0.617 ≈ ¥156/月电费**；若复用既有 24h 常开机（建城渲染机同画面），增量仅 NVENC ≈ 30W → **¥20-40/月**（假设值⬜）。
- 带宽：1080p 推流建议上行 6-10 Mbps（OBS/平台惯例，假设值⬜）→ 24h 单路 ≈ 2.6TB/月上行；观众侧 CDN 由平台承担，商家侧仅出上行——用既有居民宽带为沉没成本（现金增量 ¥0）⬜；若未来多路/企业宽带则另计。
- **结论**：五形态直播的算力/带宽现金增量 ≈ ¥20-156/月/路——相对毛利可忽略，直播的真正成本是「人/号」与流量（F4）。

## 单位经济模型

### M1 净价与毛利公式

- `净收入/单 = P × (1−r) × (1−f)`（基准 r=8%⬜，f=5%⬜；全额退款不收平台费，故退款只拖累收入端）
- `毛利/单 = 净收入 − 算力成本`（算力成本=生成直接成本，见 M2 两口径）
- `月毛利 = Σ各档单量×单位毛利 − 增量固定成本（推流电费）`；全口径压力测试再减机队 ¥1,693-2,010。

## 算力成本账本设计（本司独有面·入 Tools T-20260924-01）

**口径 L1-L3 定义（与集团 token-economy 路由三问同源）：**
- **L1**=本地免费层（Ollama qwen2.5:7b 级）：零现金 API 费，只记机时→电费/折旧；
- **L2**=本地高配层（qwen2.5:14b 级/更大模型）：零 API 费，机时更长；
- **L3**=云端 API（GLM 等）：真金 COGS，**api_reason 必填**（商品履约/直播互动/会员服务）。

**成本归集四规则：**
1. **直接成本**（L3 tokens×单价 + 商品履约机时电费）：订单级直接记账；
2. **半固定成本**（推流路电费）：直播场次为成本中心，按场内成交归因分摊（或记获客成本）；
3. **固定成本**（机队折旧+集团自耗电费）：月度池→**记「承载面」科目，不进商品 COGS**（本司使命=承载集团算力成本，商品毛利反哺承载面，防止毛利失真）；
4. **集团自耗**（OSLoop/建城）：tokens 行照记，`api_reason=-`。

**账本表字段设计（ledger.csv，每订单/每场次/每月汇总三种粒度）：**

| 字段 | 类型 | 说明 |
|---|---|---|
| date | 日期 | YYYY-MM-DD |
| product | 商品 | 摆件9.9/角色中档/房间高阶/会员三档/连麦9.9/B端API |
| order_id | 订单号 | 抖店订单号/会员ID/场次号（集团自耗行填 -） |
| cost_item | 成本项 | api/电费/折旧/推流/平台费/退款拨备/3090基金计提 |
| tier | 口径 | **L1/L2/L3** |
| tokens_local | int | 本地 tokens（L1+L2） |
| tokens_api | int | 云端 tokens（L3） |
| api_reason | str | 商品履约-订单号 / 直播互动-场次 / 会员服务-会员ID / **-（集团自耗）** |
| amount | ¥ | 该成本项金额 |
| revenue | ¥ | 标价（实付） |
| platform_fee | ¥ | f=5% 实算（全额退款单为 0） |
| refund_provision | ¥ | r=8% 计提（实退款冲回） |
| gross_margin | ¥ | revenue×(1−f)−refund_provision−直接算力成本 |

**与集团 token-economy 轮账本行兼容**：本表 `tokens_local/tokens_api/api_reason` 三列即轮账本行 `tokens: local=N api=N api_reason=-` 的逐笔明细；月末汇总行直接产出轮账本格式（`api_reason=-` 表示该轮纯集团自耗；商品履约轮汇总为 `api_reason=商品履约`）。**示例月汇总行**：`tokens: local=2,400,000 api=180,000 api_reason=商品履约(312单)+会员服务(45会员)`。

## 结论：单位经济成立否（三档判定）+ 最大成本风险

- **保守档：条件成立**——纯 9.9 结构需 541 单/月（18 单/天）且退款率 ≤15%；直播流量不稳即断，判定为「**有条件成立**」；
- **基准档：成立**——290 单/月（10 单/天）或 ~220 会员；毛利率 83-87%，算力成本占比 <1%，毛利天花板由流量而非成本决定；
