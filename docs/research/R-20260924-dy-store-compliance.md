# R-20260924 抖音小店（抖店）准入合规调研——AI 虚拟场景定制服务 + 直播带货变现

> 溯源：派驻：BigCompute 调研波 1 · 2026-09-24 · CEO 令「全面调研，派驻专家」
> 调研人：BigCompute 派驻专家（第 1 路：抖音小店准入合规）
> 状态：**调研完成（v3 终版）**。全部网络证据访问日期 = **2026-09-24**（Asia/Shanghai）。
> 诚实律：凡未能核实的信息一律标 ⬜ 存疑；官方源与第三方源严格区分；不含编造内容。

## 待答问题
1. 「AI 定制服务/虚拟商品/数字内容」在抖店属于什么类目？该类目对个人店/个体店/企业店各开放与否？
2. 三种开店主体（个人店/个体工商户店/企业店）各需什么资质（营业执照？）与保证金金额？
3. 虚拟商品发货规则（如何标记发货？）与退款规则：七天无理由退货对虚拟/定制类商品适用吗？定制类商品豁免条款？
4. 平台技术服务费/佣金率（含直播带货成交口径）？
5. 平台对 AI 生成内容商品、数字藏品/纪念证书/虚拟权益类商品的特殊限制或禁令（NFT 类禁令现状）？

## 发现

### 1. 类目归属与主体开放度
- **抖店不存在一级「虚拟商品」类目**。官方类目入驻页一级类目约 50 个（服装、食品、教育培训、文娱、通讯充值、有价券、书籍/杂志/报纸、文玩收藏等），虚拟/数字类业务分散挂靠在**教育培训**（/category/1000003616）、**文娱**（/category/1000001469）、**通讯充值**（/category/1000001824）、**有价券**（/category/1000008906）等类目之下。证据：抖店官网类目页 https://fxg.jinritemai.com/category （官方，2026-09-24）。
- ⬜ **「AI 定制服务/AI 虚拟场景」无官方专用类目**：官方子类目数据须在抖店后台「资质资费」页登录后查询，本次外部抓取未能取得二三级类目清单。第三方口径称虚拟充值/游戏服务类为**定向邀约（报白）类目**，部分要求增值电信业务经营许可证（ICP）；「AI 头像/形象定制」商家多挂教育培训或文娱类目——均为 ⬜ 存疑，需以抖店后台类目查询工具结果为准。
- **个人店类目极度受限**：第三方详解称 2026 年个人店仅开放「小众手作、文创、小型家居」等类目（食品/美妆/服饰/3C/母婴等禁止入驻）。来源：cnblogs.com/doudaxia/p/21145092（2026-07-05，访问 2026-09-24）⬜ 待官方核实。**含义：虚拟服务类目事实上要求个体工商户/企业主体。**
- 官方权益差异佐证主体分层：无执照个人店仅享「部分类目 0 佣金 + 0 保证金试运营」2 项权益；有执照商家享六大权益（含一证开 20 店）。证据：https://fxg.jinritemai.com/question/license （官方，2026-09-24）。

### 2. 开店主体资质与保证金
**资质（官方源，逐字可信）：**
- **个体工商户店**：需 个体工商户营业执照 + 经营者身份证 + 店铺名称；
- **企业店**（含企业店/专营店/专卖店/旗舰店/官方旗舰店五种店铺类型）：需 企业营业执照 + 法人身份证 + 店铺名称 + 品牌资质等；入驻流程为提交材料（约30分钟）→平台审核（1-3个工作日）→对公/实名验证（1-3个工作日）；
- **个人店（无营业执照）**：仅需 个人身份证 + 店铺名称 + 经营地址——**个人店当前仍在官方开放**。
- 证据：抖店官网入驻材料页 https://fxg.jinritemai.com/question/license 、https://fxg.jinritemai.com/enter/quali-fee （官方，2026-09-24）。**结论：BigCompute（集团子公司，有企业执照）走企业店零障碍；若先低成本试水，个体工商户店即可覆盖虚拟服务类目。**

**保证金（第三方详解，⬜ 金额需以抖店后台公示为准）：**
- 结构 = **基础保证金**（主体×类目定档，多类目经营按最高档收一笔）+ **浮动保证金**（按月支付 GMV：0-5万元→0 元；5-10万元→2000 元；>10万元→5000 元；每月1日核算、8日补缴）。
- 2026 年参考档位：个人店统一 500 元（仅限小众类目）；个体店：普通日用 500-1000 / 服饰 2000 / 个护清洁、家居大件 5000 / 酒类、小家电 1 万 / 二手手机、医疗器械 2 万；**企业店约为同类目个体店的 2 倍**。
- **0 元试运营**：新店累计订单 ≤200 单且支付 GMV ≤1 万元内可免预缴，超限后 48 小时内补齐；二手手机、医疗器械等高风险类目不适用。
- 逾期不补缴的处罚：先以货款抵扣→限制上新/下单→7 天后冻结提现、商品下架；严重违规可直接划扣保证金赔付消费者。
- 关店可申请全额退保；经营中多缴部分每月可申请退保提现（限2次/月）。
- 来源：https://www.cnblogs.com/doudaxia/p/21145092 （2026-07-05，自称依据《2026 保证金管理规范》整理，访问 2026-09-24）⬜ 全部金额待抖店后台「资质资费」页核实。
- ⬜ **教育培训/文娱（虚拟服务）类目的具体保证金档位未在公开渠道取得**，按第三方档位推算大概率落在 2000-5000 元区间，必须登录后台核实后才能入 BLUEPRINT 成本模型。
- 官方人工咨询热线（可作核验渠道）：950518。证据：fxg.jinritemai.com 页脚（官方，2026-09-24）。

### 3. 虚拟商品发货与退款规则
- **「普通虚拟商品业务模式」已于 2025-02-28 23:59:59 起取消**：该模式指上架时选择虚拟商品、履约为「无需物流配送及电子交易凭证」的自发货模式。自该时点起，虚拟类目商家**新增发品不再支持勾选该模式，存量商品亦不再允许售卖**，虚拟行业线上入驻产品整体升级。证据：官方公告《抖店【本地虚拟】取消普通虚拟商品业务模式的调整公告》 https://school.jinritemai.com/doudian/web/articlev0/aJLMgHrFEQ4q （官方页面存在；原文为 JS 渲染，关键条款经多个搜索摘要交叉核实，2026-09-24）。
  - **对本司含义**：不能再用「勾个虚拟商品→无需物流→发网盘链接/账号」的老链路。新链路需接入平台升级后的产品模式（本地虚拟/电子交易凭证/卡券核销一类），具体接入方式 ⬜ 须向平台招商或 950518 确认——这是**准入设计的第一硬约束**。
- **七天无理由退货**：法律基础《消费者权益保护法》第25条——**消费者定作的商品、在线下载或拆封的数字化商品不适用七天无理由退货**。平台规则《七天无理由退货服务规范》（2024-06-21 生效修订版）与之一致；2026-06-12 另有《售后争议处理总则》生效。证据：baike/云享客服转载规则原文 https://www.yunxiangkf.com/2024/06/24/【抖音】丨《七天无理由退货服务规范》修订-6月21/ 、新浪 https://k.sina.cn/article_7879923126_1d5ae15b606801my1u.html 、法律解读 https://ailegal.baidu.com/legalarticle/qadetail?id=0c59e0b56fc654250628 （访问 2026-09-24）。
- **定制类商品豁免**：抖音电商定制商品交易规则明确「定制商品不支持七天无理由退货」；但①订单中混有非定制品的部分仍可退换；②**商家未提前告知关键信息（如制作周期、误差范围）导致纠纷的，支持买家拒收或退货退款**。证据：知乎专栏解读 https://zhuanlan.zhihu.com/p/2050882479448445599 （访问 2026-09-24，⬜ 原文《抖音电商定制类商品交易规则》细则条款未直接核到）。
- **对本司含义**：商品页必须明示「AI 定制服务·生成周期·定制类不适用七天无理由」；但因虚拟/数字商品纠纷实践中平台倾向保护消费者（「仅退款」机制滥用风险），**售后与纠纷成本需在定价中预留**（此句为专业判断，非规则条文）。

### 4. 技术服务费/佣金率
- **机制**：技术服务费按**商品类目**设定费率，在每笔订单货款结算时同步扣取，与成交渠道（商城/短视频/直播挂车）无关。第三方常见口径：**0.6%-5%**（个别类目更高）。证据：https://zhuanlan.zhihu.com/p/626732624 、https://ailegal.baidu.com/legalarticle/qadetail?id=cb4b2106a8e83f251107 （访问 2026-09-24，⬜ 具体类目费率须以抖店后台《基础技术服务费费率标准》为准）。
- **2025 年费率标准修订**：抖音电商发布《关于修订〈2025 基础技术服务费费率标准〉的意见征集通知》，将大量原 2%-4% 档的「非标+二手+高纠纷」类目整体上调至 **5%**。证据（标题+摘要）：https://www.toutiao.com/article/7591448515872555526/ （访问 2026-09-24，原文 JS 页未抓到全文 ⬜）。
- **直播带货口径**：商家侧技术服务费同口径按类目计收，直播成交不额外加价（第三方共识 ⬜）；若通过**精选联盟**找达人带货，平台从**达人佣金**中另扣约 10% 技术服务费（第三方说法，https://scm.ecer.com/topic/detail-815997...html，⬜ 待官方核实）。本司计划为「自有账号直播带货自有商品」，无达人佣金层。
- **开放平台费用独立**：抖店开放平台（open.jinritemai.com，LLM→Unity→发放背包若走 API 对接会用到）的技术服务费为**预充值、按调用量、月结扣款，不退款不可提现**。证据：官方文档 https://op.jinritemai.com/docs/guide-docs/1281/3393 （官方，2026-09-24）。
- ⬜ **教育培训/文娱（虚拟）类目的现行费率未取得官方数字**——这是成本模型的待核项（后台「资质资费」可查）。

### 5. AI 内容/数字藏品/虚拟权益红线
- **AI 生成内容强制标识（已生效）**：抖音 2023-05-09 发布《关于人工智能生成内容的平台规范暨行业倡议》要求 AI 内容显著标识；自 **2025-09-01** 国家《人工智能生成合成内容标识办法》施行起，抖音全面执行：AI 生成内容必须**显式标注「AI生成」并写入隐式元数据标识**，未标识内容将被**限流、下架或由平台追加标识**。证据：百度百科词条（规则名+发布日期）、IT之家/头条 https://www.toutiao.com/article/7545024466590515750/ 、新浪 https://news.sina.cn/bignews/2026-04-22/detail-inhvkqhe4338747.d.html 、抖音生活服务 2026-04-22 专项 AIGC 创作规范（访问 2026-09-24）。**对本司含义：所有 AI 生成的展示素材/宣传内容/直播画面须标识「AI 生成」，这反而是卖点可合规运营。**
- **数字藏品/NFT 推广已被明令禁止**：抖音 **2025 年 12 月**起将「数字资产」与虚拟货币交易并列**禁止推广**；微信视频号 2026-04-01 生效《金融行业公约》更明确将「推广数字藏品（NFT）」列为八类禁止内容之一（与虚拟货币并列，属高风险投资项目）。处罚：限流、删除、取消认证、封号。证据：深圳文交所公众号（搜狐转载）https://www.sohu.com/a/1004019732_99927700 、https://www.metawalk.cn/2026/04/19/平台封杀nft推广？带你读懂数字藏品合规边界/ （访问 2026-09-24）。**对本司含义：产品定位「项目内使用权·不可转让·无升值属性」是正确且必要的防御设计——任何「限量」「编号」「升值」「收藏证书」话术都会把商品推进数字藏品禁区；「纪念证书」类 SKU 慎用，不得出现稀缺性/投资性表述。**
- **教培/虚拟类商品宣传专项治理（2026，官方公告全文已核）**：平台打击「过度承诺或夸张宣传课程/教辅等材料效果」「隐瞒信息诱导购买额外增值服务」等行为，依据《商家【虚假宣传】细则》《商家【严重违规营销】实施细则》《「虚假宣传：售后服务不符」实施细则》《商家【诱导第三方】细则》《创作者「诱导第三方」实施细则》等，处置包括**违规商品下架/封禁、关闭电商权限、停业整顿、店铺清退**。证据：官方公告原文链接 https://school.jinritemai.com/doudian/web/articlev0/aJkbJcvudktf （官方页存在），全文经课堂街 2026-07-11 转载核得 https://www.ketangjie.com/hyxw/14231.html （访问 2026-09-24）。第三方补充称受限话术包括「永久有效、包过押题、站外引导、二次收费」等（shuishoukefu.com 博客，⬜）。
- **通用红线「诱导第三方」（站外引导）**：不得诱导用户脱离平台场景交易/交流（加微信、站外收款等）——「订单回调→发放用户账号背包」的平台内闭环交付符合要求，但客服话术与商品详情页严禁出现站外引导。
- ⬜ **「付费连麦 ¥9.9」**：付费连麦属直播互动/连麦功能或小程序能力，**不是抖店商品形态**；若经购物车售卖「连麦服务」需走虚拟服务履约链路，若直接站外收款则触「诱导第三方」红线。此项需单独一轮调研直播/小程序侧规则。

## 结论三问
- **能不能卖？** 能，但有硬边界。「AI 虚拟场景定制服务」可以以虚拟服务类目（挂靠教育培训/文娱等，具体以抖店后台类目工具为准）在抖店售卖并直播挂车；前提是接入 2025-03 起升级后的虚拟商品产品模式（电子凭证/卡券类履约），不能用老的「无需物流自发货」链路。个人店名义可开但类目覆盖不了虚拟服务，**实际经营必须个体工商户或企业主体**。唯一高危 SKU 是「付费连麦」——非抖店商品形态，需另行评估，不进首期购物车。
- **要什么资质与成本？** 资质：个体店=个体工商户营业执照+经营者身份证+店铺名称；企业店=企业营业执照+法人身份证+店铺名称（+品牌资质如需旗舰店）。BigCompute 有企业执照，企业店可直开；个体店可低成本试水。成本：①保证金（基础档按类目，虚拟/教培类目参考区间 2000-5000 元，企业店约为个体店 2 倍；新店 0 元试运营=订单≤200单/GMV≤1万元内免缴；GMV 上月>10万时浮动加 5000 元）⬜ 金额以后台公示为准；②技术服务费按类目 0.6%-5% 计（教培/文娱类目费率待查），直播成交同口径不加价；③开放平台 API 用量费另计；④AI 标识合规无直接费用但需工程支持（显式+元数据标识）。
- **什么类目+什么红线？** 类目：教育培训/文娱等类目下的虚拟服务细目（无「AI 服务」专用类目，具体细目与报白要求登录后台「资质资费」页查询；虚拟充值/游戏等属定向邀约）。红线五条：①AI 生成内容强制标识（2025-09-01 起，未标识→限流/下架）；②数字藏品/NFT 推广禁令（2025-12 抖音起）——不得有任何稀缺/编号/升值/收藏投资性表述，产品定位「项目内使用权·不可转让·无升值属性」为合规底线而非营销选项；③虚拟商品宣传治理——不得过度承诺效果、隐瞒信息诱导二次消费、二次收费；④「诱导第三方」（站外引导加微信/收款）为清退级红线，交付必须平台内闭环；⑤定制/数字化商品不适用七天无理由（须在商品页明示并保留告知记录），但质量/描述不符争议仍须承担退款责任。
