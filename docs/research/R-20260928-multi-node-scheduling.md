## 三、本轮实测增量（17:0x 哨兵轮·T-31 部分卸载档·bm-a 4070S 12GB）

7b serve（U240 常驻标准·5.1GB 100% GPU Forever）共卡让路律内探针（state/trial-bonsai-20260928-1701/probe.log）：

| 档 | 生成速度 | VRAM 面 | 备注 |
|---|---|---|---|
| CPU 档 -ngl 0（09-28 13:32 trial） | 3.20 tok/s | 零占（+0.3GiB CUDA ctx） | 27B Bonsai CPU 32 核 |
| **部分卸载 --ngl 32（本窗）** | **4.89-5.47 tok/s** | **+3.9GB**（7315→11176MiB·余 907MiB） | load 137.8s（冷载+VRAM 上传）·质量 3/3 零错数维持 |
| 全 GPU 档 --ngl 99 | ⬜ 本窗不可行 | 需 ≈5.5GiB 权重+KV>空闲 4.97GiB | 7b serve=常驻标准在役禁抢（让路律）·顺延 7b 维护窗/独立 VRAM 窗 |
| 对照 7b GPU 常驻 | 83.4-89.8 tok/s | 5.1GB | qwen2.5:7b-instruct（Apache 2.0） |

**发现 1（headroom 判据）**：ngl 32 后余量 907MiB<1.5GB=已压 YELLOW-HEAVY 保护线（§五 VRAM<1.5GB 判据）边缘——**共存部署必须预留 ≥1.5GB headroom**，否则主归属任务增量即过载；本探针即停即清（server stopped·VRAM 归还）。
**发现 2（档位放置表 v0.1·建议级）**：判断/摘要/初筛交互件=7b GPU 档（83-90 tok/s）·批式重摘要/长上下文=CPU+RAM 档（3.2-5.5 tok/s·批式可容忍·bm-a 96GB 优势）·交互式生产禁落 CPU 档（延迟不可接受）·27B 级深度件=16GB 档 bm-c 或独立 VRAM 窗（共存部分卸载仅 1.7× 加速=不经济）。
