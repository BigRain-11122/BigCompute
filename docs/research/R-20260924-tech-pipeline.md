## 发现

### Q1 抖店开放平台订单推送

1. **推送（webhook）能力确认存在**：官方文档《消息推送》（https://op.jinritemai.com/docs/guide-docs/10/99 ，经 DuckDuckGo 索引摘要，访问 2026-09-24）：「抖店开放平台提供主动推送消息服务。基于消息推送服务，只要相关事件发生，就会把对应的消息实时推送到**开发者配置的推送地址**。开发者无需通过轮询API来获取店铺数据，仅需在接收到消息后解析即可。」→ 推送模式**必须提供公网推送地址**；官方文档同时明示**轮询 API 是被认可的替代路径**。
2. **推送前置三条件**（https://op.jinritemai.com/docs/guide-docs/240/2067 摘要）：①商家对应用（appkey）完成授权 ②应用已订阅消息事件 ③事件时间晚于授权/订阅时间。另需申请 API「权限包」（如「订单/订单信息查询」，第三方文档库 github.com/union-lab/yinglong-knowledge 摘要）。
3. **拉模式官方 API 确认**：《订单列表查询》https://op.jinritemai.com/docs/api-docs/15/555 「根据条件检索满足要求的订单列表，支持下单时间和更新时间排序；最大支持查询近 90 天的数据」——纯轮询闭环在官方 API 面成立。
4. **准入门槛**：应用双轨制（官方 https://op.jinritemai.com/docs/guide-docs/7/15 摘要）：**自用型应用**=有技术能力的商家对接自己店铺；**工具型应用**=开发者上架服务市场服务多商家。第三方服务商入驻指南（https://zhuanlan.zhihu.com/p/660905339 ）：工具型「**仅支持企业入驻，个人和个体户资质无法入驻**」。自用型=商家身份即可（面向「有技术能力的商家」，https://zhuanlan.zhihu.com/p/454821643 ）。⬜ 自用型应用是否接受个体工商户店主体、消息事件名清单、验签算法细节——op.jinritemai.com 登录墙内待实测核验。
5. **回调地址技术要求**（第三方实践佐证，https://blog.csdn.net/qq_50145597/article/details/153270310 ）：需 HTTPS 公网地址，配置验证约 1 秒超时、需原样回传校验值——即传统 push 模式=一台带公网 IP 的服务器，与零常驻红线冲突。⬜ 超时/验签细节待官方原文核验。
6. **与「零服务器」红线的冲突解法（本波判据）**：
   - **解法一（MVP 首选）·拉模式**：云函数挂定时器（每 2-5 min）轮询「订单列表查询」API——零公网入站面、零验签负担、天然幂等、无常驻进程；履约延迟=轮询间隔（数字商品可接受）。
   - **解法二·托管回调**：云托管 HTTP 触发器承接推送地址——属红线允许面「公共商业面允许平台托管（微信云托管类）」；回调写入托管 DB 即缩容，无常驻。
   - **解法三·服务商代管**：抖店服务市场现成工具代管订单/发货（见 Q2）——合规最稳、成本经第三方。
   - **结论：红线不构成阻塞**——拉模式+平台托管即可全链路零常驻自有服务器。

### Q2 承接方案对比

| 方案 | 成本 | 运维 | 合规/风险面 | 结论 |
|---|---|---|---|---|
| **A. 云函数/云托管（拉模式）** | 微信云托管：CPU 0.055 元/(核·时)、内存 0.032 元/(GB·时)、公网流量 0.8 元/GB、DB 算力 0.342 元/(个·时)（官方 https://cloud.weixin.qq.com 直抓 2026-09-24）；新用户赠 400 元/3 个月额度（CPU 720 核·时等）；0.25 核+0.5GB 常驻 1h≈0.03 元。**MVP 月成本≈0-20 元（免费额度内≈0）** | 平台全托管（官方原话「无需服务器」「按实际使用量计费，精确到 100 毫秒」）；支持 HTTPS/自定义域名，可作回调地址 | 红线明文允许面（微信云托管类）；数据经腾讯云 | **MVP 主选** |
| **B. 字节系云**：火山引擎函数服务 veFaaS（官方 https://www.volcengine.com/docs/6662 「事件驱动的无服务器函数托管计算平台」）；「抖音云托管」（官方 https://cloud.douyin.com 「服务于抖音开放生态……为应用（**小程序、小游戏、小玩法**）开发者提供后端服务」） | ⬜ veFaaS 单价未抓到；抖音云托管定位为小程序生态，**非抖店电商侧专用** | 同为全托管 | 生态同源（字节）看似自然，但抖店电商对接官方路径=开放平台 API+任意服务端，字节云无特殊通路优势 | 备选；抖音云托管与抖店订单管线**不同轨**（诚实记录） |
| **C. 第三方代管（抖店服务市场）** | 服务商入驻：**仅企业**+服务市场保证金约 2 万元（爱企查聚合 https://aiqicha.baidu.com/details/ugknowledge?id=ae338be7a1fdc34b0c5c97e9b9c58721 摘要，⬠二级源）；或直接购买现成工具（如「阿奇索」自动发货，https://zhuanlan.zhihu.com/p/2048767483658744437 ：买家付款后自动发虚拟商品，支持网盘链接等无卡密形式） | 近零运维（买服务） | 商家购买服务市场工具=平台内合规；数据经第三方 | **作为交付环节的加速件**（自动发货工具），非订单承接主体 |

运维结论：A 方案=自研轻代码（1 个轮询 Worker+1 张任务表）；C 方案=零代码但数据与交付链路受制于人。MVP 判据：**订单捕获用 A（拉模式），交付环节择优嵌入 C 的现成工具（可选）**。

### Q3 LLM 通道：GLM 云 API vs 本地 Ollama qwen2.5:7b

1. **GLM 现价（2026-09-24 抓取）**——⚠️ 官网 open.bigmodel.cn/pricing 为 JS 壳无法直抓，以下为聚合器实时价+多源交叉：
   - GLM-4.6（355B/激活 32B/200K 上下文）：智谱官方通道 **输入 2 元 / 输出 8 元**（每百万 tokens），实测吞吐 ≈23 t/s（聚合器 https://ai.bimant.com/ai-prices/model/GLM-4.6/ 直抓 2026-09-24；官方模型卡 https://docs.bigmodel.cn/cn/guide/models/text/glm-4.6 经 DDG 摘要）。
   - GLM-5.3 旗舰：**输入 8 元 / 输出 28 元**（每百万 tokens，1M 上下文）；GLM-4.7-Flash 等 Flash 系列**长期免费**；新用户注册赠 **2000 万 tokens**（chooseai.net《2026最新智谱GLM API价格表》DDG 摘要 + 知乎 https://zhuanlan.zhihu.com/p/1981490495994737726 ）。
   - 旗舰款按输入长度**分段定价**+缓存命中价+Batch 折扣存在（iqilian.com DDG 摘要）⬜ 具体档位表待官网核验；**速率限制/并发档位 ⬜ 未核验**（tokenplan.vip 摘要提示存在限流与免费额度分层）。
2. **本地栈（官方 https://ollama.com/library/qwen2.5 直抓 2026-09-24）**：qwen2.5:7b=**4.7GB**（Q4 量化）、**32K 上下文**、纯文本；同系 14b=9.0GB。4070S 12GB 显存：7b 全量 GPU 卸载+充足 KV 余量（14b 可载入但余量紧，仅备用）。生成速度≈50-80 t/s（公开基准经验区间 ⬜ 待本机实测归档）。
3. **质量-成本-速度三角**：
   - 质量：GLM-4.6/5.3（激活 32B+）在长文本创作、复杂指令、代码上显著强于本地 7B；7B 在**结构化短输出**（JSON 蓝图、属性词条、命名、短 bio）上与云差距收窄。⬜ 分任务基准待抽测。
   - 速度：本地 7B（~50-80 t/s）≥ 云 GLM-4.6（~23 t/s 实测）——短任务本地反而快，且无网络抖动。
   - 成本：本地边际≈电费（一次生成 3-5 min 高负载 ≈0.02-0.05 元/单）；GLM-4.6 按 2K 入/1K 出 ≈**0.012 元/单**；GLM-5.3 ≈0.044 元/单；Flash=0。云端成本在任何定价档下都**不构成瓶颈**（9.9 元商品毛利可忽略其占比）。
4. **路由建议（接集团 token 路由三问）**：
   - **L1 确定性**（不调模型）：SKU 规格解码、预制件参数表、调色板/词条查表——生成器本体就是查表+装配，占单量的大头。
   - **L2 本地 7b**：结构化 JSON 生成（属性卡/对话/命名/短 bio）、批量离线渲染队列内容、隐私敏感与夜间无人值守时段任务——**默认通道**。
   - **L3 云 GLM**：买家可读的品牌级长文案（角色背景故事、房间介绍，决定客单价体验的「重内容」）、复杂指令理解、L2 置信度低/失败时的兜底——**按单限预算 0.05 元闸**，超出自动降级。
   - 物理件影响：GLM API key（CEO 清单）**非 MVP 阻塞件**——Flash 免费档+新户 2000 万 tokens 足够覆盖 L3 兜底用量，key 可延后采购。

### Q4 MVP 最小闭环（账号依赖绕开方案）

**结论：可行。「抖音订单号=发放凭证 + 生成结果私信交付」不依赖硅基域账号体系（M2-M3 未建）即可成单履约。**平台面证据：抖店虚拟商品支持「电子交易凭证/无需物流配送」提取方式与自动发货（网盘链接等无卡密交付，知乎 https://zhuanlan.zhihu.com/p/2048767483658744437 、抖音搜索页摘要 2026-09-24）——交付物走平台内通道，符合「履约全部走抖音平台」红线。

- **方案 B（无依赖·快上线，本波推荐 MVP 首版）**：买家下单（SKU 规格编码定制需求）→ 拉模式捕获订单 → 本地生成 → **飞鸽 IM 私信发图片 + 视频/高清图短链**（订单号为唯一凭证，链接挂订单号哈希防白嫖）→ 后台标记发货（电子凭证形式）。不依赖：硅基域账号/支付/钱包（M2-M3）。增量依赖：抖店开店资质（归波1）、自用型应用（⬜ 主体细则待核）、云函数+DB+对象存储（免费额度内）、本地工作站（现成）、OBS 直播演示（现成）。风险：交付无账号绑定=「使用权」兑现凭据薄（订单号即权益），图片可复制（使用权属性本禁交易，可接受）；人工私信交付 2-5 min/单。
- **方案 A（完整依赖·M2-M3 后切换）**：用户抖音授权登录硅基域 → 订单号绑定硅基域 UID → 生成资产自动入背包 → 站内查看/穿戴。依赖：M2-M3 账号+支付、BigDomain 背包系统、订单与 UID 映射（⬜ 抖店订单字段是否含买家 open_id 待核验；隐私合规走平台脱敏规则）。迁移路径：B→A 平滑（历史订单凭订单号补绑），B 不产生废弃代码（任务表/路由器/生成器全复用）。
- **两版成本估算**：B 版月增量成本 ≈ **0-50 元**（云托管免费额度内≈0；生成<0.05 元/单；人工私信交付；推流电费单列见 Q5）；A 版在此基础上增加背包发放接口开发（内研人力，无增量云成本）。单量成本弹性：云成本随单量近线性但基数极低（100 单/月全链云端承接≈几元级）。

### Q5 直播推流成本（一句结论）

推流软件 **OBS Studio**——官方定位原文「**Free and open source software for video recording and live streaming**」（obsproject.com 直抓 2026-09-24），零软件授权费；4070S NVENC 硬件编码（OBS 内置编码器选项，⬜ 该细节非官网原文、属常识性事实，建议 infra-5 以设置面板实测确认）：**24h 推流的算力成本≈一台常开 PC 的电费**——按 300W 均值、0.6 元/度估算 ≈**130 元/月**，编码走 GPU 专用单元、对生成负载挤占小；推流协议/无人值守/平台政策细节归 infra-5 调研波（防双建），300W 为假设值 ⬜ 待 infra-5 实测修正。

[买家] 抖店下单支付（SKU 规格编码定制类型）

→ ②[生成工作站·出站轮询] 领取 pending 任务
→ ③[路由三问] L1 查表出确定性参数（颜色/词条/模板）→ 不足则 L2 本地 qwen2.5:7b 生成结构化 JSON 蓝图/短文案 → L2 置信低/长文案则 L3 GLM 云兜底（限预算）

→ ⑤[合规自检] 本地敏感词+人工抽检+AIGC 标识（法务面）
→ ⑥[对象存储] 上传结果，短链挂订单号哈希，任务状态=done
→ ⑦[交付] B 版：飞鸽 IM 私信发图+链接 → 后台电子凭证标记发货；A 版：背包发放接口+站内信
→ ⑧[对账] 发货状态回写抖店；售后单轮询到 → 冻结/作废链接 → 平台内退款
→ ⑨[直播演示面] 生成过程 OBS 画面同步（演示即转化，CEO 方案「直播演示生成全过程」）

### 失败处理（退款/生成失败重试）

- **生成失败**：任务表标 failed → 自动重试 ≤3 次（指数退避；L2 失败自动升 L3）→ 仍败转人工兜底队列（工作台/直播现场处理）→ **支付后 24h 仍无结果=主动走抖店平台退款**（不拖到平台赔付线，权利第一）。
- **买家退款/售后**：轮询到售后单 → 未开始任务立即取消；已完成则作废结果短链 → 履约退款全走平台（红线），IM 致歉话术模板。
- **幂等**：order_id 主键——推送重推/轮询重叠不重复生成。
- **超时预警**：支付后 2h 未交付=工作站告警；24h=强制退款流程。
- **内容安全双闸**：生成前（输入侧敏感词）+ 交付前（输出侧自检+人工抽检）；AIGC 标识强制（法务终审件）。
- **履约时长判据 X（供 BLUEPRINT §五.4 定标）**：拉模式+本地生成全链路「支付→交付」目标 ≤30 min、P95 ≤2h、硬顶 24h（超时主动退款）。
