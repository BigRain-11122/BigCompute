## 四、统计摘要与簇分析

1. **全时段**（n=29）：mean=**81.92 tok/s**·median/P50=**88.04**·P10=**31.32**·P90=**98.17**·min=29.69（13:36）·max=103.07（10:03）·极差比 **3.47×**。
2. **竞争窗低值簇**（09-28 13:01-15:51·5 点 <70：31.32/29.69/60.99/33.86/30.68）：**成因交叉坐实**=同窗 GPU 采集器 mem_used 8456-11373 MiB（vs 09:31 基线 6632 MiB·Tuanjie/Blender 他司产线显存挤占 +2-5GB）+15:18 功率峰 199.82W/util 99%（渲染峰）。**簇内间隙恢复证据**：13:47=101.03/15:34=97.05 两点回满速=他司活载**间歇性**，探针落间隙即恢复——共享卡竞争=脉冲型吞吐压制非持续降级。
3. **净窗稳定性**（09-29 00:12-04:50+10:50/11:06·7 点·无他司产线活载）：92.58/92.57/96.73/95.60/95.19/91.54/97.32→mean=**94.50 tok/s**·sd=2.27·**CV=2.4%**（紧带）；09-28 夜窗 22:28-23:24 三点 mean=82.30（疑 Blender 尾载·注记不归净窗）。**口径对照**：E12 长 prompt 探针（22:43）80.8/81.3 与同段短探针 82.88/77.72 量级相合=短探针对中等负载代表面初步成立（样本 1 次·观察位）。
4. **判读**：本机 4070S 共享卡环境下，常驻 7b 生成吞吐呈**双态**——净窗 ~94.5 tok/s（CV 2.4%）vs 竞争窗下探至 ~30（0.32×净窗）。

## 五、SLA 面判读（建议级·试点未批零承诺动作）

1. **双态 SLA 结构**：BC-P-04/BC-P-11 若批，SLA 承诺应分「独占/净窗」与「共享窗」两态——共享态若按净窗值承诺吞吐即结构性违约面（本序列 P10=31.32 实证）。建议级结构=**常驻可用性为主指标**（uptime：零缺位周观察窗 7/7 达成+丢而复得实证在档，见 tech T15）+**吞吐分级承诺**（净窗带 ~94.5±2.3%/共享窗「尽力而为」标注）。
